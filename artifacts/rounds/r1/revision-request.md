# 제안서·견적서 r1 — 반려 사유와 수정 요청

r1 초안 평가에서 반려된 항목의 위치·근거·수정 요청을 한 번에 전달합니다. 수정본은 r1 초안을 보존하고 `artifacts/rounds/r2/draft.md`에 저장합니다.

- 대상 초안: [artifacts/rounds/r1/draft.md](draft.md)
- 수정 원칙: 예산·기간·수수료율·목표·업무 범위는 바꾸지 않습니다. 금액·성과 수치는 독립 검산과 모두 일치했으므로, 아래 서술 보완 외에 수치를 바꾸면 해당 계산 전체를 다시 맞춥니다. 수정 전후 내역은 고객 본문에 넣지 않습니다.
