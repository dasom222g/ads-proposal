# 요구사항 정의서 — 무브펫

포커싱온이 무브펫에 제출할 광고 제안·견적의 필수 조건을 원문 위치와 연결한 문서입니다. 작성 전 필요한 결정과 계약·집행 전 확인 사항을 구분합니다.

- 문서 버전: movepet-requirements-v1, 2026-10-11.
- 구분의 상태: `제공 정보`는 원문에 기재된 사실·제품 정보로 외부 검증을 뜻하지 않습니다. `확정 조건`은 이번 제안에 적용할 고객·회사·양식의 요구이며 계약 체결을 뜻하지 않습니다. `제공 가정`은 계획·계산 전제이며 실측치가 아닙니다. `미정`은 작성자 제안 또는 별도 확인이 필요한 사항입니다. `충돌`은 동시에 적용할 수 없는 입력입니다.
- 현재 입력 사이에서 작성 전에 해결해야 할 충돌은 발견되지 않았습니다. 미정 사항은 아래 두 확인 표에 구분했습니다.
- 검사 ID는 기존 체크리스트 양식의 C01~C12에 대한 연결안입니다. 이번에는 체크리스트를 작성하거나 판정 기준을 확정하지 않았습니다. 동일 요구의 여러 출처는 한 요구에 함께 연결하며, 같은 문제를 중복 집계하지 않습니다.
- 원문 행 번호는 위 작성일에 읽은 파일 기준입니다. 링크는 해당 파일의 절로 이동하며, 행 번호·표 항목을 함께 적었습니다.
